# Лабораторна 3 • додаткові завдання

~~~powershell
git switch --detach lab03-full
dotnet run --project src/Cli -- data/sample.json
dotnet run --project src/Cli -- data/mixed.csv
dotnet run --project src/Cli -- data/sample.csv
~~~

Розширення файла визначає імпортер через switch expression. JSON містить масив книг BookDto. Імена полів допускають різний регістр. Некоректний елемент отримує повідомлення з порядковим номером. Інші елементи масиву продовжують оброблятися. Синтаксично пошкоджений JSON спричиняє файлову помилку з кодом 1.

Для змішаного CSV додай заголовок `type;fields`. Префікс B означає книгу у форматі B;id;isbn;title;year. Префікс R означає читача у форматі R;id;ім’я з необов’язковим полем email. Один switch розпізнає префікс і створює відповідний DTO. Заголовок відрізняє змішаний каталог від класичного CSV, у якому навіть R може бути ідентифікатором книги.

| Файл | Усього | Прийнято | Пропущено | Помилок |
| --- | ---: | ---: | ---: | ---: |
| sample.json | 3 | 2 | 1 | 33,33% |
| mixed.csv | 4 | 3 | 1 | 25,00% |
| sample.csv | 13 | 10 | 3 | 23,08% |

Кількість записів дорівнює сумі прийнятих і пропущених. Заголовки, коментарі та порожні рядки CSV не входять у суму. Частка помилок дорівнює 100 × пропущені / усі. Для порожнього набору програма показує 0%.
