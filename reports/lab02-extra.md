# Лабораторна 2 • додаткові завдання

З кореня CrossApp на тегу lab02-full виконай команди PowerShell.

~~~powershell
dotnet run --project src/Cli -p:DemoFramework=net8.0
dotnet run --project src/Cli
./scripts/Compare-Publish.ps1
~~~

Перший запуск показав .NET 8.0.11 і «збірка Core під net8.0». Другий показав .NET 10.0.12 і «збірка Core під net10.0». Властивість DemoFramework вибирає сумісну версію Cli для демонстрації. Компілятор Core вибирає текст BuildNote через директиву #if.

Скрипт створює окремі каталоги у TEMP. Для кожного режиму він вимірює всі файли й запускає Cli.exe --json з каталогу публікації. Виміри для Release, net10.0, win-x64:

| Режим | Файлів | Байтів | Запуск |
| --- | ---: | ---: | --- |
| Framework-dependent | 7 | 225146 | успішно |
| Self-contained | 194 | 80609498 | успішно |
| Self-contained + PublishSingleFile | 3 | 73581020 | успішно |
| Self-contained + PublishTrimmed | 35 | 20545385 | успішно |

Single-file пакує компоненти у виконуваний файл. Файли символів PDB залишаються поруч. Trimming вилучає невикористаний код. Якщо програма знаходить член типу через рефлексію лише під час виконання, аналізатор може вилучити потрібний член. Для звіту JSON компілятор генерує метадані з ReportJsonContext. Перевірена trimmed-публікація завершилася без попереджень ILLink. Виконуваний файл повернув коректний JSON.
